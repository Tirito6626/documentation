---
title: Intialization
---
So, you installed xmanage and proved it's working. But what's next?

## Initialize the core directory
```
# ./xmanage initialize
[Info] Starting initialization
```
You can also initialize API folder if you want to use it later
```
Do you want to enable API? (can be enabled later) [Y/n] 
... 
[Info] Done
```
After it's done initializing without errors, run you can create your first server:

```bash
xmanage server create
```

It will ask you for server's information, RAM, CPU and etc.

Check `xmanage help` to get all commands and how to manage your server
