## Requirements
- jq
- gawk
- grep
- tput
- systemd 
- coreutils
- bash
- nano (?)
- ncat 
- Basic Linux understanding

<Steps>

## Installation
1. Install required packages
<Tabs>
<TabItem label="Debian-based distributions">
```bash 
apt install jq gawk coreutils nano ncat
```
</TabItem>
<TabItem label="RedHat-based distributions">
```bash
# RPM
rpm -i sudo jq gawk coreutils nano ncat
# DNF
dnf install sudo jq gawk coreutils nano ncat
# YUM
yum install sudo jq gawk coreutils nano ncat
```
</TabItem>
<TabItem label="Arch-based distributions">
```bash
pacman -S sudo jq gawk coreutils nano ncat
```
</TabItem>
<TabItem label="Alpine">
```bash
apk add sudo jq gawk coreutils nano ncat
```
</TabItem>
<TabItem label="Gentoo">
```bash
emerge sudo jq gawk coreutils nano ncat
```
</TabItem>
</Tabs>
2. Download the latest release from the XManage Repository
```bash
wget https://repo.tirito.de/projects/xmanage -O /usr/bin/xmanage
```
3. Make the downloaded file executable
```bash
chmod +x /usr/bin/xmanage
```
4. Run the executable
```bash
xmanage --version # or /usr/bin/xmanage --version
```
</Steps>
